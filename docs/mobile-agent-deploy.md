# Mobile Agent 装机指南（MI 10S，目标：对话唤起酷狗）

日期：2026-11-03。基于 Mobile Agent v0.2.0 实测信息整理。

## 1. 为什么选它（与 kgJP 的契合点）

- v0.2.0（2026-09-28）**新增 skills 支持 + skill 创建工具**——我们的 kugou-launch 技能可以直接喂进去。
- **唤起酷狗不需要 Root**：它的「系统功能」能力组原生支持"打开深链接"，`kugou://` 深链正好走这条路；
  设备操作（无障碍/Root）只在深链失败后的降级方案里才用。
- OpenAI 兼容模型服务，endpoint/model/key 自定义——可以接任意兼容网关。
- Android 7.0+ 即可（MI 10S 的 Android 12/13 满足）。

下载后校验 sha256 再安装（设置里允许安装未知来源应用）。

## 3. 首次配置

1. **模型服务**：设置 → 模型服务 → 高级设置，填 OpenAI 兼容的
   Endpoint / 模型 ID / API Key。要求模型支持 function calling（工具调用）。
2. **启用工具**：设置 → 工具管理，至少启用：
   - 「系统功能」——深链打开走这里（第 3 步唤起的首选通道）
   - 「网络/网页读取」——搜索酷狗接口取 hash 用
   - （可选）「设备控制」——降级方案用，需要无障碍权限；不 Root 也能装
3. 授权档位建议先"每次询问"，跑顺后改"始终允许"。

## 4. 安装 kugou-launch 技能

Mobile Agent v0.2.0 内置 **skill 创建工具**，两种装法：

- **App 内创建**（推荐）：在对话里让 agent "创建一个技能"，然后把
  [`skills/kugou-launch/mobile-agent.md`](../skills/kugou-launch/mobile-agent.md)
  的内容粘贴给它作为技能正文。
- **手动录入**：技能管理页新建，标题"打开酷狗音乐并播放指定歌曲"，
  正文同上。

注意：用的是 **mobile-agent.md**（深链版），不是 SKILL.md（命令版）——
Mobile Agent 不接受任意 shell，`am start` 那套在它里面用不了。

## 6. 已知限制与风险

- 项目处于早期（v0.2.0），接口和交互可能变；文档明确提示不要用于支付/账号安全操作。
- 模型请求会把对话内容发给所配的第三方模型服务——注意隐私边界。
- skill 的具体文件格式仓库里暂无文档（`skills/` 目录为空、架构文档更新早于 skill 功能），
  上面的装法基于"skill 创建工具 + 技能管理页"的 UI 途径，若 App 内格式要求不同，按 App 引导适配。
- MIUI 权限：悬浮窗、后台弹出界面、通知使用权按需授予；"后台弹出界面"权限被拦时深链唤起可能静默失败。

## 7. 与既有方案的关系

- **不冲突**：Termux 路线（`termux/kgjp.py`）保留为保底——任何能跑 shell 的环境都可用。
- Mobile Agent 跑通后，它是"对话式唤起"的最佳宿主；Termux 路线退为调试/自动化通道。
- 若 v0.2.0 的 skill 机制不兼容粘贴式创建，回退到推荐排序里的下一项（ZorvAI 的 MCP 通道）。
