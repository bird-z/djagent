# kgJP MVP · 在小米 10S 上跑通

## 它是什么

一个**单文件 HTML 页面**，10.5 KB，无依赖、离线可用、不需要装任何东西。
打开后选一个场景，页面给出一首歌 + 一句推荐理由 + 两个按钮（在酷狗播放 / 网页版）。

目的不是功能完整，是**验证深链能不能在 MIUI 上真正唤起酷狗**。

---

## 怎么传到手机（三选一）

### 方式 A：微信文件传输助手（最省事）

1. 手机微信 → 文件传输助手
2. 电脑上把 `mvp/index.html` 拖进去
3. 手机上点开文件 → 右上角「…」→ **用其他应用打开** → 选 **Chrome**
   （⚠️ 不要用微信内置浏览器，它拦 scheme）

### 方式 B：小米互传 / USB 拷贝

1. USB 连电脑，选「传输文件」
2. 拷到手机 `Download/` 目录
3. 手机打开「文件管理」→ 找到 `index.html` → 点开 → 选 Chrome

### 方式 C：adb（如果你有开发环境）

```bash
adb push mvp/index.html /sdcard/Download/kgjp.html
adb shell am start -a android.intent.action.VIEW \
  -d "file:///sdcard/Download/kgjp.html" \
  -t "text/html"
```

⚠️ adb 这条路在 MIUI 上需要先开「开发者选项 → USB 调试（安全设置）」，
否则 `am start` 会被拒绝。

## 跑通判定标准

打开页面后，**先点页面底部的「全部测一遍」**，它会展开诊断日志。

然后依次验证，记录结果：

| # | 操作 | 期望 | 如果不对说明什么 |
|---|---|---|---|
| 1 | 点场景「写代码 / 专注」 | 出现一张卡片，含理由、歌名、两个按钮 | 页面本身有问题 |
| 2 | 点「▶ 在酷狗播放」 | **酷狗 App 弹出并进入播放页** | 见下方排查 |
| 3 | 点「网页」 | 浏览器打开酷狗网页版单曲页，能看到《潮汐》 | 网络或链接问题 |
| 4 | 酷狗里看歌曲名 | 显示「傅梦彤 - 潮汐 (Natural)」 | 落点错，说明参数不对 |

## 排查表

**点「在酷狗播放」完全没反应**

1. 确认手机上装了酷狗音乐（不是酷狗概念版、不是 Lite 版）
2. 换成 Chrome 打开本页重试（微信/QQ 内置浏览器、小米浏览器都可能拦自定义 scheme）
3. 还是没反应 → 说明 `kugou://start.weixin` 这个协议在 MIUI 上被系统拦了，
   或者酷狗版本已废弃该协议。**这是 L2 方案失败，需要转 L1（官方 SDK）**

**酷狗弹出来了，但停在首页，没进播放页**

- 协议只做了「打开」，没解析 hash 参数。
- 尝试：把 `cmd` 从 212 改成其他值，或检查 hash 是否要**大写**。
  当前 MVP 用的是小写 `a4713521...`，可以试 `A4713521...`
- 这属于协议参数不匹配，需要抓包或找酷狗版本对照测试。

**弹出来了，也进播放页，但歌不对**

- 大概率落到搜索结果页了。看酷狗里的歌曲名是否为「傅梦彤 - 潮汐」。
- 如果显示「搜索：傅梦彤 - 潮汐」说明当前生效的是网页兜底，不是 App。

**点「网页」都打不开**

- 网络问题，或酷狗网页版需要登录。这与 MVP 无关，基线问题。

## 这一版故意没做的

- **AI 选歌**：曲库只有 1 首（《潮汐》，已验证），其他场景留空。
  在跳转链路没验通之前，堆选歌逻辑是浪费。
- **三端适配**：只做安卓。Win/Mac 的唤起机制完全不同，等这端结论出来再谈。
- **去重 / 历史 / 偏好**：没有持久化。
- **错误反馈**：MV 阶段不做 toast，失败静默——但诊断日志里能看到点击记录。

---

## 验证完之后

把「全部测一遍」的日志截图发我，重点看三件事：

1. `play` 那行的链接是否被点击后触发了跳转
2. 酷狗弹出来的落点是首页还是播放页
3. 歌曲名对不对

根据结果决定下一步：
- **能播** → 开始填曲库、接场景识别，MVP 成立
- **只能到首页** → 试改动 cmd / hash 大小写，或转 L1
- **完全唤不起** → L2 方案作废，必须走官方 SDK（要 appid + 审核 + 付费）
