# kugou-launch（Mobile Agent 适配版）

> 本文件供 Mobile Agent v0.2.0+ 的 skill 创建工具粘贴使用。
> 与 `SKILL.md`（命令版）的区别：Mobile Agent **不接受任意 shell**，
> 唤起酷狗走它的「系统功能 → 打开深链接」能力，不走 `am start`。

## 技能名

打开酷狗音乐并播放指定歌曲

## 技能描述（给 agent 的指令）

当用户要求播放歌曲、打开酷狗音乐、推荐并跳转音乐时，按以下步骤执行：

### 第 1 步：确定歌曲与 hash

- 用户给了歌名：调用酷狗搜索接口获取 hash（见下）。
- 用户没指定歌曲、只说场景（如"来点专注音乐"）：从下方内置曲库选一首，说明推荐理由。

搜索接口（无需 key，优先用网页读取工具访问）：

```
http://mobilecdn.kugou.com/api/v3/search/song?format=json&keyword=<URL编码歌名>&page=1&pagesize=5
```

取 `data.info[0].hash`（32 位十六进制）。核对歌名和歌手是否匹配用户意图。

### 第 2 步：拼深链

payload 模板（JSON 需整体 URL 编码）：

```
kugou://start.weixin?{"cmd":212,"jsonStr":{"hash":"<hash>","filename":"<歌手> - <歌名>","extname":"mp3"}}
```

编码规则：`{"` → `%7B%22`，`:` → `%3A`，`,` → `%2C`，`}` → `%7D`，中文照常 UTF-8 百分号编码。

### 第 3 步：唤起（按顺序降级）

1. **深链唤起**（首选）：用「系统功能」工具的"打开深链接"能力打开上面的 `kugou://` 链接。
   预期：酷狗打开；理想：自动开始播放。
2. **只开 App**（深链无效时）：用设备工具（需无障碍/Root 权限）的应用启动功能打开酷狗
   （包名 `com.kugou.android`，从应用列表取真实包名），然后告知用户手动搜索歌名。
3. **浏览器兜底**：告诉用户网页播放链接
   `https://m.kugou.com/share/song.html?chain=<chain>`（若有 chain）。

### 第 4 步：验证并汇报

- 若有截图/识别能力：确认酷狗是否在前台、是否在播放。
- 该协议已于 2026-11-03 在小米 10S 真机验证：**深链唤起酷狗并自动播放指定曲目均生效**
  （Mobile Agent「系统功能」通道，无需 Root）。若个别机型/版本行为不同，如实汇报实际表现。

## 编码示例（可直接用）

《潮汐》深链整体 URL 编码后：

```
kugou://start.weixin?%7B%22cmd%22%3A212%2C%22jsonStr%22%3A%7B%22hash%22%3A%22a4713521e4754b8ed3f09af1e41756e5%22%2C%22filename%22%3A%22%E5%82%85%E6%A2%A6%E5%BD%A2%20-%20%E6%BD%AE%E6%B1%90%22%2C%22extname%22%3A%22mp3%22%7D%7D
```

## 注意事项

- 不要求 Root：深链打开走「系统功能」能力组即可；只有第 3 步降级方案 2 需要无障碍/Root。
- 「系统功能」工具需在工具管理里启用（权限档位建议"每次询问"或"始终允许"）。
- 付费/登录限制由酷狗 App 自行处理，agent 不处理支付和账号操作。
